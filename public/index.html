Arquitectura Técnica del Port Web

Detalles de implementación basados en el Plan de Portabilidad WebAssembly.

⚙️ Motor de Ejecución

  • Compilador: Emscripten (Clang / LLVM) → WebAssembly (WASM 32-bit)
  • Subsistema Gráfico: SDL2 mapeado a HTML5 Canvas 2D / WebGL 2.0
  • Audio: SDL2 Audio Mixer mapeado a Web Audio API (44.1 kHz, 16-bit estéreo)
  • Control: Pointer Lock API para mouse nativo de ARPG sin salir de ventana

💾 Manejo de Memoria (1.9 GB)

  • Límite WASM: Espacio de direccionamiento de 32 bits (máx. 2-3 GB por pestaña)
  • Estrategia VFS: Streaming de bloques y lectura por demanda en StormLib
  • Persistencia: IndexedDB con navigator.storage.persist() permanente
  • Save Games: Sincronización bidireccional mediante FS.syncfs

🛡️ Flags de Compilación Emscripten

emcc src/main.cpp \
  -s USE_SDL=2 \
  -s ALLOW_MEMORY_GROWTH=1 \
  -s INITIAL_MEMORY=512MB \
  -s MAXIMUM_MEMORY=2048MB \
  -s ASYNCIFY \
  -s IDBFS \
  -O3 -o public/d2engine.js

📁 Directorio de Desarrollo Local
